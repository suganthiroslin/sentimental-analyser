About SentimentAI

SentimentAI is an AI-powered Natural Language Processing system designed to analyze the emotional tone of text. The system identifies whether the given sentence expresses a positive, negative, or neutral sentiment.

How It Works

The user enters a sentence into the system. The text is processed using Natural Language Processing techniques and a machine learning model analyzes the text to determine its sentiment.

Key Features

  • Positive, Negative and Neutral sentiment classification
  • Natural Language Processing
  • Machine Learning based prediction
  • User registration and login
  • Sentiment analysis history
  • Simple and user-friendly interface

Technology Used

Frontend: HTML, CSS, Tailwind CSS
Backend: Django
Database: SQLite3
AI/ML: Python, NLP and Machine Learning
